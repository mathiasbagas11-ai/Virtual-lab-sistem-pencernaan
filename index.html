📖 Cara Pakai Lab Ini

  1. Peta Organ — arahkan kursor ke organ bernomor untuk melihat namanya, klik untuk membuka kartu fungsi & enzimnya.
  2. Perjalanan Bolus — kolom kiri = cerita perjalanan makanan + Mode tebak; kolom kanan = Galeri Proses berisi gambar pencernaan mekanik & kimiawi tiap organ (klik gambar untuk memperbesar).
  3. Uji Makanan — pilih sampel + reagen, lalu uji. Catat hasilnya ke tabel.
  4. Tabel Pengamatan — diskusikan pola data dengan teman sebangku. Unduh CSV untuk laporan.
  5. Kuis & Game — akhiri dengan kuis HOTS atau game sortir untuk menguji pemahaman.

🏅 Lencana yang bisa dikumpulkan

Lihat deretan lencana di header. Lencana terbuka saat kamu membuka 8 kartu organ, menuntaskan perjalanan bolus, mendapat 4 hasil uji positif, mencatat 5 baris data, dan meraih skor kuis ≥ 80%.

⌨️ Pintasan keyboard

Tombol 1–5 untuk lompat antar stasiun, ← / → untuk maju-mundur di Perjalanan Bolus, Esc untuk menutup jendela.

🖼️ Kalau gambar tidak muncul

Klik tombol 🔍 di header. Lab akan menguji semua file gambar satu per satu dan melaporkan mana yang ketemu dan mana yang tidak. Lab juga otomatis mencoba beberapa kemungkinan nama file (.png, .webp, .jpg, bahkan ekstensi dobel seperti .png.webp) di folder img/ maupun folder utama.

💾 Tentang data tabel

Tabel pengamatan tersimpan otomatis di browser ini, jadi aman kalau halaman ter-refresh. Tapi data tidak ikut pindah ke komputer lain — unduh CSV kalau mau dilaporkan.
