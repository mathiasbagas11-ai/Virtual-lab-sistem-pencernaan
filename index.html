📖 Cara Pakai Lab Ini

  1. Mulai dari Peta Organ — arahkan kursor ke organ bernomor untuk melihat namanya, klik untuk membuka kartu fungsi & enzimnya.
  2. Perjalanan Bolus — kolom kiri = cerita perjalanan makanan + Mode tebak; kolom kanan = Galeri Proses berisi gambar pencernaan mekanik & kimiawi tiap organ.
  3. Uji Makanan — pilih sampel + reagen, lalu uji. Catat hasilnya ke tabel.
  4. Tabel Pengamatan — diskusikan pola data dengan teman sebangku. Unduh CSV untuk laporan.
  5. Kuis — akhiri dengan kuis HOTS atau game sortir untuk menguji pemahaman.

️ Kalau Gambar Tidak Muncul

Klik tombol 🔍 Cek Gambar di header. Lab akan menguji semua file gambar satu per satu dan melaporkan mana yang ketemu dan mana yang tidak. Lab juga otomatis mencoba beberapa kemungkinan nama file (.png, .webp, .jpg, bahkan ekstensi dobel seperti .png.webp) di folder img/ maupun folder utama.

⚠️ Catatan Penting

Data tabel akan hilang kalau halaman di-refresh. Salin atau unduh CSV dulu sebelum menutup halaman.
